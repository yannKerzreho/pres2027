# mode où Mélenchon (mu 0,09 -> 0,22) passe à droite de Roussel et Tondelier

# MÊME énergie potentielle (-3952 ± 11), ce n'est pas un piège de warmup (1500
# pas de warmup n'y changent rien). Avec jax 0.11 / numpyro 0.22 (versions non
# épinglées du runner), une chaîne sur quatre y tombe dans 3 graines sur 4 ->
# R-hat 1,9 à 2,5, publication refusée. Avec les versions ci-dessous, 0 graine
# sur 4, résultats identiques au chiffre près entre Python 3.9 et 3.11.
#
# C'est un pansement : il reproduit le comportement des fits publiés jusqu'ici,
# il ne tranche pas la bimodalité, qui est une question de modèle. Le garde-fou
# RHAT_PUBLIABLE reste le filet. Ne pas dépiner sans avoir réglé ça.
